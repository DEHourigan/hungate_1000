# Predicted structures of circular and Class IIa bacteriocins from the Hungate1000

This directory contains predicted three-dimensional protein structures for circular and Class IIa bacteriocins identified within the Hungate1000 culture collection. These bacteriocins were selected based on curated biosynthetic gene clusters and represent rumen-associated peptides of interest due to their antimicrobial activity and ecological relevance.

Protein structures were predicted using AlphaFold2. For each bacteriocin, the top-ranked model (based on AlphaFold confidence ranking) is provided. Where applicable, per-residue confidence scores (pLDDT) were used to assess model reliability, and these predictions should be interpreted accordingly.

All structures presented here are *in silico* predictions and have not been experimentally validated by X-ray crystallography or NMR unless explicitly stated elsewhere. As such, these models are intended to support comparative structural analysis, hypothesis generation, and visualisation of predicted folds rather than definitive structural confirmation.

The files in this directory can be used for downstream analyses such as structural alignment, fold comparison, or visualisation in molecular graphics software (e.g. PyMOL or ChimeraX). Additional details on model generation, selection criteria, and limitations are described in the Methods section of the accompanying manuscript.
